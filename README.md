## Запуск локально

1. Склонируйте репозиторий:

   ```bash
   git clone https://github.com/<ваш-логин>/<название-репозитория>.git
   ```

2. Перейдите в папку проекта:

   ```bash
   cd <название-репозитория>
   ```

3. Откройте `index.html` в браузере или запустите Live Server в VS Code.

## Деплой на Netlify

1. Залейте проект в GitHub.
2. В Netlify выберите **Add new site → Import an existing project**.
3. Подключите репозиторий и нажмите **Deploy**. Сборка не нужна, достаточно указать корневую папку.

Также можно перетащить папку проекта на [Netlify Drop](https://app.netlify.com/drop).
